# App Design Architect — installatie

## In Claude.ai
Upload het ZIP-bestand als een custom Skill via de Skills-instellingen van Claude, voor zover beschikbaar op je account. Gebruik de instructies uit de actuele Claude-documentatie als de interface is gewijzigd.

## In Claude Code / GitHub-project
Kopieer de map `app-design-architect` naar `<repository>/.claude/skills/app-design-architect/` zodat `<repository>/.claude/skills/app-design-architect/SKILL.md` bestaat. Commit de bestanden als je de skill in dit project wilt bewaren en delen.

## Persoonlijk voor alle lokale projecten in Claude Code
Plaats de map onder `~/.claude/skills/app-design-architect/`.

## Gebruik
Roep de skill aan als `/app-design-architect` (in Claude Code), of vraag Claude expliciet om App Design Architect te gebruiken. Begin bijvoorbeeld met een UX-audit voordat je code wijzigt.

## Belangrijk
Deze Skill geeft Claude instructies, maar verleent niet automatisch internettoegang, GitHub-toegang, browserbediening of mogelijkheden om code uit te voeren. Die zijn afhankelijk van de Claude-omgeving, permissies en beschikbare tools.
