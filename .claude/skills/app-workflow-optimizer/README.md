# App Workflow Optimizer — Claude Skill

Een herbruikbare Nederlandstalige Skill voor het verbeteren van workflows in interactieve HTML-applicaties.

## Installatie

**Claude.ai:** upload `App-Workflow-Optimizer-Claude-Skill.zip` als aangepaste Skill als jouw Claude-abonnement en interface dit ondersteunen.

**Claude Code:** plaats de map `app-workflow-optimizer` in `<project>/.claude/skills/`, inclusief `SKILL.md` en de map `references`.

## Gebruik

Voorbeeldprompt:

> Gebruik de App Workflow Optimizer om mijn rijlesplanner te analyseren. Onderzoek de flow van een rijles inplannen, wijzigen en annuleren. Geef quick wins, een verbeterde flow en acceptatiecriteria. Verander nog geen code.

## Werkafspraken

- Analyse eerst, implementatie alleen na opdracht.
- Bescherm rollen, gegevens en bestaande functies.
- Werk samen met de App Design Architect Skill voor de visuele uitwerking.
