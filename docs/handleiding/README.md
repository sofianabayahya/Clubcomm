# Functiekaarten (Besluit 151)

*Per functie één kaart: bovenaan de status in de app, de besluiten, de schermafbeeldingen en de doelgroepen; daaronder alleen de blokken die nodig zijn (Kort · Meer · HJO · Beheerder · Let op). Besluiten geven het waarom; de kaart verwijst ernaar. Een gepubliceerde uitgave bevat alleen kaarten met de status In productie. Schermafbeeldingen staan in `docs/presentaties/beelden` (alleen demo of testscherm, geen echte namen).*
