# DCG-methodiek (alleen voor DCG)

**Let op: deze documenten gelden alleen voor RKSV DCG.** Ze zijn de eigen methodiek van de initiatiefnemer. Andere clubs die ClubComm afnemen volgen de visie van de KNVB (standaardprofiel `supabase/profielen/knvb-*.json`). Niets hieruit hoort in de code of in de standaard; het komt alleen in het **DCG-opleidingsprofiel** (Besluit 121 en 123: methodiek als gegevens per club).

| Bestand | Inhoud | Rol |
|---|---|---|
| `01-kerndocument-v1.0.md` | Methodologisch model leren voetballen, v1.0, 26-09-2026 | **Leidende bron.** Bij verschil gaat dit document voor. |
| `02-acht-universele-voetbalproblemen.md` | De 8 problemen met definitie, centrale vraag, waarnemen, keuze WAT/HOE, gereedschappen, oplossingen, complexiteitsopbouw, O12-eindbeeld, matrix probleem × gereedschap | Uitwerking |
| `03-ho-spoor-methodologische-leerlijn.md` | HO-spoor: 5 leerniveaus, representativiteit, mengpaneel, coachcyclus, periodisering | Uitwerking |
| `04-trainersspoor.md` | Trainersspoor: trainingsroute, coachvragen, evaluatiekaart | Praktisch werkdocument. Zijn voorlopige lijst van 12 problemen is vervangen door de 8 uit het kerndocument. |

De database (het DCG-profiel) wordt op deze documenten gecontroleerd, niet andersom. Audit: `audit-2026-10-28.md`.
